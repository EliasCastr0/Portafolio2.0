# Portafolio 2.0 - Elias Castro 🚀🛡️

¡Bienvenido al código fuente de mi portafolio profesional versión 2.0!
Este proyecto ha sido completamente rediseñado con un nuevo enfoque mucho más robusto, interactivo y centrado en mi perfil de **Ciberseguridad, Soporte Técnico y Redes**.

## 💻 Nuevo Enfoque Bi-lateral: Seguridad & Sistemas
A los conocimientos previos de administración de sistemas y soporte IT (ABM, Microsoft 365, PowerShell), se le sumó un diseño con orientación y herramientas dedicadas a **Ciberseguridad Analítica y Ofensiva**.
* **Integración del estilo "Hacker":** Fondos oscuros, terminaciones verdes neón (glassmorphism/hacker style) y transiciones fluidas.
* **Módulos Reales:** Incorpora habilidades como Análisis Forense, Inteligencia de Fuentes Abiertas (OSINT), Bug Bounty y redes, resaltando un perfil mixto preparado tanto para infraestructura como para la defensa activa.

## ✨ Características Principales
1. **100% Bilingüe Dínámico (ES/EN):** Se implementó un algoritmo robusto en JavaScript para intercambio de idioma estático en tiempo real mediante los atributos `data-i18n`. Todo el portafolio (textos, botones y barras) se traduce al instante y guarda la preferencia del usuario.
2. **Mobile First & Ultra Responsivo:** Utiliza grillas (CSS Grid, Flexbox) y media-queries de última generación para visualizarse de forma perfecta en monitores, tabletas y cualquier dispositivo móvil, adaptando incluso jerarquías de texto pesadas (`max-width: 768px`, etc).
3. **Optimizado para Cargas Rápidas:** Imágenes pre-procesadas de manera local (`img/`) para garantizar máxima eficiencia, evitando cortes en la red o hipervínculos caídos de la web.
4. **Carrusel de Contenido en Bucle:** Animación CSS infinita para resaltar publicaciones y recursos técnicos compartidos en YouTube y LinkedIn.

## ⚙️ Tecnologías Utilizadas
* **HTML5:** Estructuración semántica en la jerarquía.
* **Vanilla CSS3:** Overrides completos con animaciones nativas sin uso estricto de librerías extra, para garantizar extrema velocidad y personalización "pixel-perfect".
* **JavaScript:** Lógica asíncrona de modo oscuro/claro y manejo integral del "Language-Switch".
* **Phosphor Icons:** Iconografía corporativa limpia y adaptable mediante su CDN oficial.

## 🚀 Despliegue
Este repositorio está diseñado para una Integración Continua (CI/CD) utilizando **Netlify**. Cualquier avance fusionado a la rama `main` reconstruye y pone en línea las alteraciones automáticamente.
